## About Me

I'm a BSc CSIT graduate focused on **cybersecurity, computer networks, and systems**. I learn by building—turning concepts into practical projects around vulnerability assessment, network intrusion detection, security monitoring, and secure application design.

My background spans programming, algorithms, operating systems, cryptography, cloud computing, and AI. I'm deepening my expertise in the security challenges that emerge when real systems meet real users and threats.

**Currently exploring:** Vulnerability Assessment · Network Security · Threat Detection · Cloud Security · DevSecOps
