## About Me

I'm a BSc CSIT graduate with a growing focus on cybersecurity, computer networks, and systems.

My earlier projects were mostly focused on application development. As I worked through operating systems, computer networks, cryptography, and cloud computing, I became increasingly interested in the security problems behind the systems I was building.

That interest has shaped the projects I'm working on now, particularly around vulnerability assessment, network intrusion detection, security monitoring, and secure application design.

I learn primarily by building and testing systems myself, using projects to turn concepts into something practical.
